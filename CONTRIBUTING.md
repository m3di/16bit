# Contributing

Thanks for your interest. This is a personal project with one maintainer, built largely by a team of AI agents. Issues and pull requests from anyone are welcome.

## Before you start

- For anything larger than a small fix, open an issue first so the direction can be agreed.
- Read [docs/DECISIONS.md](docs/DECISIONS.md). Changes that go against a recorded decision need the maintainer's agreement before any code is written.

## Pull requests

- One change per pull request, with tests.
- `pnpm lint`, `pnpm typecheck`, and `pnpm test` must pass.
- Describe what changed and how you tested it.
- Only the maintainer merges pull requests from outside the agent team. Review may take a while.

## Sign-off

Contributions are accepted under the project's licence, Apache 2.0. Add a sign-off line to each commit to confirm you have the right to submit it, as described by the [Developer Certificate of Origin](https://developercertificate.org/):

```
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds it for you.

## Security

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on this repository.
