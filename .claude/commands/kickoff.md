Read `KICKOFF.md` and carry it out step by step, in order.

Start with step 1: ask the maintainer the four questions in one message and wait for the answers before doing anything else. Do not create the GitHub repository until the owner, name, and visibility are confirmed.

If the directory already has git history and a GitHub remote, kickoff has been done: say so and suggest `/standup` instead.
